# Echo Hub

Echo reporting, calculators, view-by-view scanning tips, measurement caveats, teaching diagrams and reference values in one Android app (plus a web version).

- Reference values are restated from BSE, ASE/EACVI, ESC/ERS and related guidelines (cited in the app).
- Tips, caveats and diagrams are original to this app.
- Reports stay on the phone. Don't enter patient identifiers.

Pushing to `main` builds the APK with GitHub Actions and publishes it as the latest release.
